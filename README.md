# Venti UI

VentiUI, Is a project made with TailwindCSS, Framer-Motion, clsx and Tailwind-Merge
It is designed to be a minimal, accessable and polished UI component library for React-based projects.
It can be themed using shadcn globals.css style Variable CSS.

It supports:
- React
- Next.js
- Vite

Also its typesafe :D
